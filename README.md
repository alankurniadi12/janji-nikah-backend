# Janji Nikah Backend

Backend Janji Nikah adalah API Express.js + MongoDB untuk platform undangan pernikahan digital.

Stack:

- Express.js
- MongoDB + Mongoose
- Google OAuth
- Hybrid JWT/session-cookie auth
- Multer or equivalent upload middleware
- Sharp or equivalent image compression

Catatan:

- Do not commit real environment files or uploaded assets.
- Internal product documents are kept private and are not committed to this repository.
